# The Book of Enoch — Modern Edition Website

A reader website for the Book of Enoch, harmonizing the translations of **R. H. Charles** (1912) and **Richard Laurence** (1821) into a modern interpretation.

## ✨ Features

- 📖 **Section 1 Ready**: Contains all 36 chapters and verses of *The Book of the Watchers*.
- 🏛️ **Architecture for All 7 Sections**: Built-in navigation roadmap prepared for Sections 2 through 7.
- 🌓 **Themes**: Switch between **Dark Mode**, **Light Mode**, and **Sepia/Papyrus Mode**. Remembers your choice in local storage.
- 🔍 **Font Size Controls**: Easily enlarge (`A+`) or decrease (`A-`) the reading font with instant adjustments.
- 🧭 **Effortless Navigation**:
  - Sticky sidebar with quick chapter numbers (1–36) grid jump.
  - Previous / Next chapter buttons in footer and keyboard arrows (`←` / `→`).
  - Reading progress bar at the top of the screen.
  - Scroll-spy indicator that highlights your current chapter as you read.
- 🔎 **Real-time Search**: Search verses for keywords or phrases with instant highlight.
- 📱 **Responsive**: Works across desktop, tablets, and phones.

## 🚀 How to Open

Double-click `index.html` in your file explorer to open it in any browser, or host it on GitHub Pages / any web server.
